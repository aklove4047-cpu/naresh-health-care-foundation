# Naresh Health Care Foundation

Official web application for Naresh Health Care Foundation – Dedicated to accessible healthcare, rural e-clinics, first aid awareness, and compassionate medical assistance.

## 🚀 Features
- **Hero & Mission**: Highlighting core initiatives, medical camps, and foundation values.
- **E-Clinics & Services**: Digital healthcare access and community clinic management.
- **Interactive UI**: Responsive layouts, clean animations, and accessibility-first design.
- **Admin & Management**: Internal administrative utilities and patient/case data handling.

## 📁 Project Structure
- `index.html`: Main landing page and web application entry.
- `css/style.css`: Core design system, responsive styles, and modern styling tokens.
- `js/`: Modular JavaScript logic (`app.js`, `admin.js`, `data.js`).
- `assets/images/`: Optimized visual assets for foundation programs.

## 🌐 Deployment
- Static web application ready for deployment on **Cloudflare Pages** or **GitHub Pages**.
